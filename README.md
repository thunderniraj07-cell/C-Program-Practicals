# C Program Practicals

Assignment 2 programs written in C.

## Programs
- **matrix_multiplication.c** : Multiplies two matrices using 2D arrays, after checking that their sizes are compatible.
- **student_result.c** : Menu-driven Student Record and Result Management System using functions, structures, pointers and files. It adds, displays and searches records, calculates total, average and grade, shows the topper and saves records to a file.
